三月七印象桌宠 1.5.0 · Windows 独立版

安装：解压后双击 PinkPixelPet-Setup.exe，再点“安装并启动”。
免安装：双击 PinkPixelPet.exe。两种方式任选一种，不要同时运行。

不需要 Codex、Python、OpenAI 账号或 API Key；离线可用。
适用 Windows 10 / 11，依赖系统自带的 .NET Framework 4.x。
安装到 %LOCALAPPDATA%\PinkPixelPet，创建“三月七印象桌宠”桌面快捷方式。
不请求管理员权限，不设置开机启动，不访问网络。

操作：
· 鼠标左键按住人物身体拖动；透明空白不接收点击。
· 单击人物：随机播放一次常规动作（含拍照）；双击人物：打开或关闭信息窗口。双击信息窗口切换时钟和倒数日。
· 倒数日 → 名称与日期：设置名称及未来 999 天内的日期。
· 信息窗口 → 大小、位置与间距：窗口可放在角色左、右、上、下方，缩放范围 50%–125%。
· 右键菜单可选择挥手等动作，以及窗口置顶和全屏自动隐藏。
· 右键菜单可手动播放“拍照”；待机 15 秒后，也会随机播放一次常规动作。
· 整点时若信息窗口正显示时钟，角色会拍照，时钟窗口同步闪光并短暂显示“整点啦”。
· 右键人物或系统托盘图标：切换动作、视线跟随、大小、回到主屏幕、退出。
· 手动选择的常规动作约 5 秒后回到待机；拍照动作播放一次后回到待机。
· 自动记住角色位置、大小、信息窗口开关与时钟/倒数日模式，以及视线跟随、置顶和全屏避让设置。
· 安装更新时保留个人设置，并清理指向本软件旧安装路径的旧名称快捷方式。
· 找不到人物时，双击系统托盘里的三月七图标。
· 卸载：Windows 设置 → 应用 → 已安装的应用 → 三月七印象桌宠 → 卸载。
· 免安装版退出后删除程序即可。

说明：此自制程序未购买代码签名证书，Windows 可能显示“未知发布者”。
仅运行你确认来源可信的副本，无需关闭系统安全功能。
