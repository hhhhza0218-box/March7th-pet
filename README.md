# March7th-pet｜三月七印象桌宠

三月七印象桌宠是以《崩坏：星穹铁道》角色三月七为原型创作的 Windows 像素风二创桌宠。她可以在桌面上拖动、播放动作，也能陪你查看日期与时钟、记录三位数倒数日；还支持窗口置顶和全屏时自动隐藏。

## 下载和安装

在仓库右侧 **Releases** 下载 `March7th-pet-Windows-v1.5.0.zip`，解压后运行 `PinkPixelPet-Setup.exe` 安装；也可以直接运行 `PinkPixelPet.exe`。程序可离线使用，适用于 Windows 10/11。更新前，请先从系统托盘退出正在运行的旧版。1.5.0 安装包已按新交互重新发布；此前下载过同名压缩包的用户需重新下载。

GitHub 自动生成的“Source code”压缩包是源码，不是安装包。`使用说明.txt` 随下载包提供。

历史安装包及每版改动见 [更新记录](CHANGELOG.md) 和 Releases。早期版本只保留了原始安装包，仓库中的源码快照对应最新版。

## 操作

### 移动角色与播放动作

按住角色身体并拖动，就能把她放到桌面的合适位置；透明空白区域不会接收点击。拖动时角色会朝移动方向播放动作，打开的信息窗口也会跟随。单击角色会随机播放一个常规动作（包括拍照），双击角色则打开或关闭信息窗口。待机 15 秒后也会随机播放一次动作。右键角色或系统托盘图标，可手动选择“挥挥手”“跳一跳”“拍照”等动作，也能开启“视线跟随鼠标”；动作播放后会回到待机状态。右键菜单的“大小”提供小号（144 像素）、标准（192 像素）和放大（384 像素）三档。

### 查看时钟与倒数日

双击角色打开信息窗口，再双击角色将其关闭；双击**信息窗口**可在时钟和倒数日之间切换。时钟会实时显示日期、星期及精确到秒的时间。若整点时窗口正显示时钟，角色会拍照，时钟窗口同步显示提示动画。倒数日显示自定义事项名称、目标日期与剩余天数；通过右键菜单 **倒数日 → 名称与日期…** 设置，日期可选今天至未来 999 天，到期显示 `000`。角色右键菜单和信息窗口右键菜单都能打开这一设置。

### 调整窗口与桌面显示

右键角色或信息窗口，选择 **信息窗口 → 大小、位置与间距…**，可将信息窗口放在角色左、右、上、下方，大小设为 50%–125%，并调整与角色的间距。角色靠近屏幕边缘时，信息窗口会调整位置，尽量保持在可见范围内。角色位置、大小、信息窗口开关与时钟/倒数日模式等设置会自动保存。

右键菜单中的 **窗口置顶** 会让角色和信息窗口保持在普通窗口前方。若同时开启 **全屏时自动隐藏**，检测到前台全屏窗口时两者会暂时隐藏，退出全屏后恢复；浏览器全屏和全屏视频也可能触发。不同游戏的全屏兼容性仍需实际测试。普通的最大化窗口不会按全屏处理。

找不到角色时，双击系统托盘图标可让她回到主屏幕；需要关闭程序时，在角色或托盘的右键菜单中选择 **退出**。

## 从源码构建

本仓库包含三月七印象桌宠完整的源码、角色配置、动画图集和拍照素材，无需下载另一款桌宠。开发端需要 Windows、Python 3，以及系统的 .NET Framework 4.x 编译器。在仓库根目录运行：

```powershell
.\build.ps1 -Python 'C:\path\to\python.exe'
```

如已设置 `PET_WORKSHOP_PYTHON`，可省略 `-Python`。构建会运行程序自检，并在 `pink-pixel-desktop` 下生成独立的安装包和便携版压缩包。下载现成安装包的用户不需要 Python。

`core/` 是桌宠工坊的共用实现。本仓库保存三月七印象桌宠的独立源码快照；维护者在工作区修复共性问题后，用 `desktop-pet-workshop/export_pink_github.py` 更新此仓库，再重新构建三月七印象桌宠。三月七印象桌宠的安装目录、设置和运行标识为 `PinkPixelPet`。
