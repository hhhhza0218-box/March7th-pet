# 三月七印象桌宠 v1.0.0

- 首个独立 Windows 桌宠：透明像素角色、拖动、动画动作、视线跟随、大小选择和托盘菜单。
- 提供安装版与便携版，离线运行。

历史版本 v1.0.0–v1.3.0 以及 v1.4.0 为原有二进制归档；本仓库当前保存的是 v1.4.1 的源码快照，不能把 GitHub 自动生成的早期标签“Source code”压缩包当作对应旧版的精确源码。

下载附件 `PinkPixelPet-Windows-v1.0.0.zip`，解压后运行 `PinkPixelPet-Setup.exe` 安装，或直接运行 `PinkPixelPet.exe`。更新前请从系统托盘退出旧版。

这是保留的原始历史安装包。GitHub 自动生成的 “Source code” 压缩包来自当前仓库源码快照，不能代表此历史版本的精确源码。

适用 Windows 10/11；程序未签名。安装包内容已校验，旧版未逐一在真实游戏和其他电脑上重新测试。
