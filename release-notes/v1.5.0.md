# v1.5.0

三月七印象桌宠的独立 Windows 安装包与便携版。本版加入六帧拍照动作，单击角色随机播放常规动作，双击角色开关信息窗口；待机 15 秒后也会随机播放动作。时钟界面整点时，角色拍照并显示同步提示动画。另修正向左拖动抖动，信息窗口支持四方向放置和 50%–125% 缩放，并记住上次状态、改进旧版升级清理。

下载 `March7th-pet-Windows-v1.5.0.zip` 并解压。运行 `PinkPixelPet-Setup.exe` 安装，或直接运行 `PinkPixelPet.exe`。从旧版更新前请先从托盘退出旧程序。此前下载过 1.5.0 同名压缩包的用户也需重新下载。

SHA-256：`feb77832dfa00b833da9700a2f20ff8198e6e8a254bdb75cc71e38897a384de4`。

已通过内置自检与压缩包校验；真实鼠标交互和全屏游戏兼容性仍需用户实测。程序未签名，适用于 Windows 10/11。
