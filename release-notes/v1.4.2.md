# 三月七印象桌宠 v1.4.2

- 对外名称更新为“三月七印象桌宠”，下载包名称统一为 `March7th-pet-Windows-v版本号.zip`。
- 保留 `PinkPixelPet.exe`、安装目录和个人设置，方便从旧版升级。
- 功能与 v1.4.1 一致：拖动、动作、时钟、倒数日、窗口置顶和全屏自动隐藏。

下载 `March7th-pet-Windows-v1.4.2.zip`，解压后运行 `PinkPixelPet-Setup.exe` 安装，或直接运行 `PinkPixelPet.exe`。升级前请从系统托盘退出旧版。

适用 Windows 10/11；程序未签名。已通过内置自检和压缩包校验；真实全屏游戏兼容性仍需用户实测。
